# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1v3JUBLFkNyoL_A5RqW3F87qq_6E1BUHg

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set `GROQ_API_KEY` for the clarity memo. Mail uses `SMTP_USER` and `SMTP_PASS` (see replit.md). The page still runs without them.
3. Run the app:
   `npm run dev`
